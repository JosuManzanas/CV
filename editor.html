☁️ Publicar en tu web (GitHub)

El editor guarda los cambios directamente en el datos.js de tu repositorio y la web se actualiza en 1–2 minutos.

  1. Abre GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → solo el de tu web.
  3. Permissions → Contents: Read and write. Nada más.
  4. Copia el token y pégalo aquí. Nunca lo compartas.
